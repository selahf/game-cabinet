# Accessibility and the Web

## Why You Need to Care About Accessibility

Well, it's the right thing to do.

But also, it helps us to develop features that can benefit *everyone*. It means that all people can use your website.

There also is financial incentive: you can get in a lot of trouble for not considering accessibility.
- Title III prohibits discrimination against people based on disability
- commerce or institution-level websites must be ADA-compliant

## Steps to Being Accessible

Web accessibility encompasses all disabilities.

There are three big things that help a lot:
- use skip navigation
    - make sure that you add a "Skip to main content" invisible button for screenreaders
    - you could also include more navigation in this as well
- ensure color contrast
    - use a contrast checker to see which contrast rules you are following
    - use this to see if the theme colors you select are compliant with the rules
    - everyone benefits from high-contrast text, so make sure you are using it
- add alt text to all images
    - it is more important to put null tags on images that don't need describing
    - but also, giving alt tags to images is important
    - make sure that the alt tags are making sense (repetition can be really annoying with screenreaders)
    - so be sure to create useful alt tags

## Testing for Accessibility

**Validators** can help to check for accessibility, but also dead code, loading times, differences between screen widths, etc.
